Configuración del Cliente Móvil

Conexión de Android Studio con EMQX Cloud

En Android nativo utilizamos la librería MqttAndroidClient sobre TCP/TLS en el puerto 8883 (con respaldo WebSocket en 8084).

Broker URL: ssl://h0bc12ce.ala.us-east-1.emqxsl.com:8883
Client ID: android-device
Usuario: android-username
Contraseña: android-username
Tópico Raíz: hogar/#
1. Protocolo SSL/TLS (:8883)

A diferencia del navegador web, Android puede abrir sockets TCP directos con cifrado SSL usando el prefijo ssl:// en el puerto 8883.

2. Client ID Exclusivo

La app Android se identifica como "android-device", mientras que la web usa "android-device-web". Así ambas permanecen conectadas sin desconectarse entre sí.

3. Hilo Principal (UI Thread)

Los eventos de MQTT llegan en un hilo en segundo plano. Por eso en Java usamos runOnUiThread(() -> ...) para actualizar textos y mostrar Toasts.

🛠️ Paso a Paso: Configuración del Proyecto en Android

Paso 1: Agregar la librería MQTT en app/build.gradle

Gradle

En el archivo app/build.gradle se declara la dependencia de Paho MQTT compatible con versiones modernas de Android (SDK 24 a 36): 

dependencies {
    implementation libs.appcompat
    implementation libs.material
    implementation libs.activity
    implementation libs.constraintlayout

    // Cliente MQTT para Android (fork actualizado de Eclipse Paho)
    implementation 'com.github.hannesa2:paho.mqtt.android:3.3.5'
}

Paso 2: Declarar Permisos y Servicio en AndroidManifest.xml

Manifest

Para que Android permita abrir la conexión a Internet y mantener vivo el servicio MQTT en segundo plano, es obligatorio registrar los permisos y el <service android:name="info.mqtt.android.service.MqttService" />: 

<?xml version="1.0" encoding="utf-8"?>
<manifest xmlns:android="http://schemas.android.com/apk/res/android">

    <!-- 1. Permisos requeridos por MQTT -->
    <uses-permission android:name="android.permission.INTERNET" />
    <uses-permission android:name="android.permission.WAKE_LOCK" />
    <uses-permission android:name="android.permission.ACCESS_NETWORK_STATE" />

    <application ... >
        <!-- 2. Servicio en segundo plano que gestiona la conexión MQTT -->
        <service android:name="info.mqtt.android.service.MqttService" />

        <activity android:name=".MainActivity" android:exported="true">
            ...
        </activity>
    </application>
</manifest>

Paso 3: Inicializar y Conectar al Broker en MainActivity.java

Conexión Java

Definimos las constantes de conexión, creamos la instancia de MqttAndroidClient en onCreate() y configuramos MqttConnectOptions con usuario, contraseña y reconexión automática: 

public class MainActivity extends AppCompatActivity {

    private static final String TAG = "MainActivity";
    // URL principal por SSL (puerto 8883) y alternativa por WSS (puerto 8084)
    private static final String MQTT_BROKER_URL = "ssl://h0bc12ce.ala.us-east-1.emqxsl.com:8883";
    private static final String[] FALLBACK_URIS = new String[] {
            "ssl://h0bc12ce.ala.us-east-1.emqxsl.com:8883",
            "wss://h0bc12ce.ala.us-east-1.emqxsl.com:8084/mqtt"
    };
    private static final String CLIENT_ID = "android-device";
    private static final String MQTT_USERNAME = "android-username";
    private static final String MQTT_PASSWORD = "android-username";

    private MqttAndroidClient client;

    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        setContentView(R.layout.activity_main);

        // Crear el cliente con confirmación automática de mensajes (Ack.AUTO_ACK)
        client = new MqttAndroidClient(
            getApplicationContext(),
            MQTT_BROKER_URL,
            CLIENT_ID,
            Ack.AUTO_ACK
        );

        connectToMqttBroker();
    }

    private void connectToMqttBroker() {
        MqttConnectOptions options = new MqttConnectOptions();
        options.setServerURIs(FALLBACK_URIS);
        options.setUserName(MQTT_USERNAME);
        options.setPassword(MQTT_PASSWORD.toCharArray());
        options.setAutomaticReconnect(true); // Reconectar si cambia el Wi-Fi o datos móviles
        options.setCleanSession(true);

        client.connect(options, null, new IMqttActionListener() {
            @Override
            public void onSuccess(IMqttToken asyncActionToken) {
                Log.d(TAG, "¡Conectado exitosamente a EMQX!");
            }

            @Override
            public void onFailure(IMqttToken asyncActionToken, Throwable exception) {
                Log.e(TAG, "Error al conectar", exception);
            }
        });
    }
}
Flujo de Salida en Android

📤 Cómo el usuario ENVÍA información (Publish)

client.publish()

Cuando el usuario presiona un botón en la pantalla del teléfono (por ejemplo, Encender Luz o Establecer Temperatura en el SeekBar), la aplicación empaqueta el texto en un objeto MqttMessage y lo publica en el tópico correspondiente.

1. Asignar los botones en Java (setupButtons):

// Botones de encendido y apagado de la luz del living
findViewById(R.id.btnLivingLuzOn).setOnClickListener(v ->
    publishWithConfirmation("hogar/living/luz/set", "on", "Luz encendida")
);

findViewById(R.id.btnLivingLuzOff).setOnClickListener(v ->
    publishWithConfirmation("hogar/living/luz/set", "off", "Luz apagada")
);

// Enviar el valor numérico del SeekBar del Termostato
findViewById(R.id.btnSetTemp).setOnClickListener(v -> {
    String temp = String.valueOf(tempSlider.getProgress());
    publishWithConfirmation("hogar/clima/temperatura/set", temp, "Temp: " + temp + "°C");
});

2. Método que envía el mensaje al Broker (publishWithConfirmation):

private void publishWithConfirmation(String topic, String payload, String msg) {
    // 1. Mostrar en el visor local y confirmar con un Toast
    appendToSubscriptionLog(topic, payload);
    Toast.makeText(MainActivity.this, msg, Toast.LENGTH_SHORT).show();

    try {
        // 2. Convertir el String (ej. "on") a arreglo de bytes
        MqttMessage message = new MqttMessage(payload.getBytes());
        message.setQos(1); // QoS 1: Entrega garantizada al menos una vez

        // 3. Publicar de forma asíncrona en el tópico (ej. "hogar/living/luz/set")
        client.publish(topic, message, null, new IMqttActionListener() {
            @Override
            public void onSuccess(IMqttToken asyncActionToken) {
                Log.d(TAG, "Publicado: " + topic + " = " + payload);
            }

            @Override
            public void onFailure(IMqttToken asyncActionToken, Throwable exception) {
                Log.e(TAG, "Error al publicar en " + topic, exception);
            }
        });
    } catch (Exception e) {
        Log.e(TAG, "Error al crear el mensaje MQTT", e);
    }
}
Flujo de Entrada en Android

📥 Cómo el usuario RECIBE información (Subscribe)

messageArrived()

Para que el teléfono reciba en tiempo real cualquier cambio hecho desde la Página Web o desde otro dispositivo, primero se suscribe al comodín hogar/# y luego escucha el callback messageArrived.

1. Suscribirse al tópico hogar/# al conectar:

private void subscribeToTopics() {
    // El comodín "#" recibe todos los subtópicos que empiecen con "hogar/"
    client.subscribe("hogar/#", 1, null, new IMqttActionListener() {
        @Override
        public void onSuccess(IMqttToken asyncActionToken) {
            Log.d(TAG, "¡Suscrito exitosamente a 'hogar/#'!");
        }

        @Override
        public void onFailure(IMqttToken asyncActionToken, Throwable exception) {
            Log.e(TAG, "Error al suscribir", exception);
        }
    });
}

2. Recibir el mensaje y mostrarlo en el Visor de la App:

client.setCallback(new MqttCallbackExtended() {
    @Override
    public void connectComplete(boolean reconnect, String serverURI) {
        // Apenas termina de conectar, activamos la suscripción
        subscribeToTopics();
    }

    @Override
    public void messageArrived(String topic, MqttMessage message) throws Exception {
        // 1. Extraer el contenido recibido en texto plano
        String payload = new String(message.getPayload());

        // 2. Pasar al hilo visual (UI Thread) para actualizar el TextView del Visor
        runOnUiThread(() -> {
            String time = new SimpleDateFormat("HH:mm:ss", Locale.getDefault())
                              .format(new Date());
            String entry = "[" + time + "] " + topic + " → " + payload + "\n";

            // Insertar al principio del historial y mostrar en pantalla
            logBuilder.insert(0, entry);
            subscriptionLogTextView.setText(logBuilder.toString().trim());

            Toast.makeText(MainActivity.this, "Recibido: " + payload, Toast.LENGTH_SHORT).show();
        });
    }

    @Override
    public void connectionLost(Throwable cause) { }
    @Override
    public void deliveryComplete(IMqttDeliveryToken token) { }
});
